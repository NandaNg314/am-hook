# am-hook v0.2.0 更新总结

## 完成的功能

### 1. GitHub Actions 自动编译

创建了两个 workflow：

#### `.github/workflows/release.yml`
- 当推送 `v*` 格式的 tag 时自动触发
- 并行编译 4 个平台：
  - Windows x86_64
  - Linux x86_64
  - macOS x86_64
  - macOS aarch64 (Apple Silicon)
- 自动创建 GitHub Release 并上传所有编译产物
- 包含缓存机制加速编译

#### `.github/workflows/build-test.yml`
- 在每次推送到 main 分支和 PR 时运行
- 在 Ubuntu、Windows、macOS 上测试编译
- 确保代码跨平台兼容性

### 2. 自动更新功能

实现了完整的自更新系统（`src/updater.rs`）：

#### 功能特性
- **检查更新**: `--check-update` 参数在启动时检查 GitHub Releases
- **自动更新**: `--auto-update` 参数自动下载并安装最新版本
- **平台支持**: 
  - Linux/macOS: 自动替换可执行文件并备份旧版本
  - Windows: 下载新版本到临时文件，提示用户手动完成替换
- **版本比较**: 自动比较当前版本和最新版本
- **安全下载**: 使用 HTTPS 从 GitHub Releases 下载

#### 使用方式
```sh
# 检查更新
am-hook --check-update --listen 0.0.0.0:8888 --wrapper-url http://127.0.0.1:12340

# 自动更新
am-hook --auto-update --listen 0.0.0.0:8888 --wrapper-url http://127.0.0.1:12340
```

## 技术细节

### 更新机制
- 使用 GitHub API 获取最新 release 信息
- 根据操作系统和架构自动选择对应的二进制文件
- 版本比较使用字符串比较（去除 'v' 前缀）
- 支持 User-Agent 识别（"am-hook-updater"）

### 安全考虑
- 只从官方 GitHub Releases 下载
- HTTPS 加密传输
- Windows 需要手动完成替换，避免运行时文件锁问题
- Unix 系统自动备份旧版本

### 跨平台兼容
- 使用 Rust 标准库的跨平台 API
- Windows 使用 `.exe` 扩展名
- Unix 系统设置可执行权限（0o755）
- 平台检测基于 `env::consts::OS` 和 `env::consts::ARCH`
